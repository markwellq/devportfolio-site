## Stack

Next.js (App Router, TS) · Tailwind CSS v4 · next-intl (`en`/`ru`/`ro`) · shadcn/ui (Base UI) · Phosphor Icons · react-icons · yet-another-react-lightbox · Bun

## Getting started

```bash
bun install
bun run dev
```

## Structure

```
app/[locale]/       pages (home, diploma, projects)
components/          UI components
data/                projects & tech stack data
lib/                 helpers (icons, youtube, etc.)
messages/            en.json / ru.json / ro.json
```
